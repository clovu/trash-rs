# trash-rs-cli

`trash-rs-cli` is the command-line interface for `trash-rs`.

## Status

- macOS: implemented
- Windows: planned
- Linux: planned

## Install

```bash
cargo install trash-rs-cli
```

## Usage

```bash
trash-rs-cli /path/to/file_or_dir
```

Help:

```bash
trash-rs-cli --help
```
